# Number Guessing Game - Python Course Project

## Overview
This is a command-line based Number Guessing Game built using Python. The program randomly selects a secret number between 1 and 100, and the player must guess it within a limited number of attempts depending on the chosen difficulty level.

## Features
- **Difficulty Levels:** Choose between 'easy' (10 attempts) or 'hard' (5 attempts).
- **Interactive Feedback:** The program tells the user if their guess is too high or too low.
- **Attempt Tracker:** Displays the remaining turns after every guess.
